FTP File Transfer Application

Privacy Policy

Effective Date: November 16, 2026
Last Updated: November 16, 2026

StackCreate Technologies ("we", "our", or "us") respects your privacy. This Privacy Policy explains how the FileLane Android application ("FileLane" or "the App") accesses, processes, stores, and protects information when you use it.

FileLane is designed to let you transfer files between your Android device and other devices, such as Windows computers, using a local FTP connection.

Important FTP Security Information FileLane uses standard FTP. Standard FTP does not encrypt usernames, passwords, or transferred file contents while they travel across the network. Use FileLane only on trusted networks and understand this limitation before connecting.

1. Information We Collect

FileLane does not require you to create an account or provide personal information such as your name, phone number, or email address to use its core file transfer functionality.

However, certain information is processed locally on your Android device to operate the application and provide its features.

1.1 FTP Login Credentials

FileLane generates FTP login credentials or allows you to configure custom credentials, depending on the available application settings.

  • FTP username.
  • FTP password.

Saved FTP credentials are stored locally using Android encrypted storage mechanisms, including Android Keystore and AES-GCM encryption.

The credentials are used to authenticate devices connecting to your FileLane FTP server. They are not intentionally transmitted to StackCreate Technologies.

1.2 Server History and Connected Devices

FileLane maintains local server-session history to provide information about previous FTP server activity.

This history may include:

  • FTP server session start and end times.
  • Session duration.
  • IP addresses of devices that connected during a session.
  • Successful upload and download counts.
  • File categories, such as images, videos, audio, documents, and archives.

The application records transfer counts by file category. It does not need to store the actual contents of transferred files in its server-history records.

Server history is stored locally on your device. The application retains up to ten recent session records.

1.3 File and Storage Access

FileLane needs access to files and folders that you choose to share through its FTP server.

Depending on your device and the storage method you select, the application may use Android storage permissions or the Android Storage Access Framework (SAF).

File access is used to provide file browsing, downloading, uploading, and related file-management operations. FileLane does not intentionally upload your personal files to StackCreate Technologies.

2. How We Use Information

Information processed by FileLane is used for the following purposes:

  • Starting and operating the FTP server on your Android device.
  • Authenticating devices connecting to the FTP server.
  • Allowing file transfers between connected devices.
  • Displaying connected-device information.
  • Maintaining server-session history and transfer statistics.
  • Supporting automatic server-stop settings.
  • Improving application reliability and security.

3. Network Connections and FTP Communication

FileLane uses Android network capabilities to operate its FTP server and communicate with connected devices.

You can use FileLane when your Android device and the connecting device are connected to the same compatible local network. Examples include:

  • A mobile hotspot shared by your Android phone.
  • A private home Wi-Fi network.
  • A compatible local Wi-Fi network.

File transfers take place between your Android device and the connecting device through the network connection.

Important: Standard FTP Is Not Encrypted

FileLane currently uses standard FTP rather than FTPS or SFTP. Standard FTP does not provide encryption for login credentials or transferred file contents.

Therefore, someone with the ability to monitor network traffic may be able to view FTP credentials or transferred information.

For safer use:

  • Prefer trusted private Wi-Fi networks.
  • Avoid using FTP over public or untrusted Wi-Fi networks.
  • Use a strong FTP password.
  • Stop the FTP server when you are not transferring files.
  • Do not share your FTP credentials with unknown people.

4. Data Storage and Security

FileLane stores its application settings, saved credentials, and server history locally on your Android device.

Saved FTP credentials are protected using encryption mechanisms provided by Android Keystore and AES-GCM.

We take reasonable measures in the application design to protect locally stored credentials and prevent unintended access to application data.

However, no application, storage mechanism, or network connection can be guaranteed to be completely secure.

5. Data Sharing and Disclosure

StackCreate Technologies does not intentionally collect or receive your personal files, FTP passwords, or local server history through FileLane's normal file-transfer operation.

We do not sell your personal information.

File transfers are initiated between your Android device and the devices you authorize to connect using your FTP credentials.

Information may nevertheless be accessible to other devices on your network if they obtain your FTP credentials or if your network is not properly secured.

6. Third-Party Services and Software

FileLane uses Android platform functionality and software libraries to provide its application features. These may include libraries for FTP server operation, network communication, and QR-code-related functionality.

The application does not require a separate third-party cloud storage account to perform its local FTP file transfer functionality.

Third-party platform services, including Android and your network provider, may process information according to their own privacy policies and terms.

7. Notifications and Background Operation

FileLane may run an Android foreground service while its FTP server is active.

A persistent notification is displayed to indicate that the FTP server is running. This allows you to be aware that your device is accepting FTP connections.

8. Data Retention and Deletion

FileLane keeps application settings and server history locally for as long as they are needed to provide the application's functionality.

Server history is limited to the ten most recent session records. Available in-app deletion options can be used to remove individual history records.

You can stop the FTP server whenever you choose. Uninstalling the application or clearing its application data generally removes locally stored application data, subject to Android device and backup behavior.

9. Backups

FileLane's Android backup configuration excludes its saved FTP credential preferences from configured cloud backup and device-to-device transfer rules.

Other application data may be subject to Android backup behavior and your device's backup settings.

10. Children's Privacy

FileLane is a general-purpose file transfer utility and is not specifically designed to collect personal information from children.

We do not intentionally collect personal information from children through the application's normal local file-transfer functionality.

11. Your Choices and Responsibilities

You remain in control of how you use FileLane.

  • You choose when to start and stop the FTP server.
  • You control which devices receive your FTP credentials.
  • You choose the storage locations and files made available for transfer.
  • You can configure your FTP login credentials using the available settings.
  • You can manage available server-history records.
  • You can revoke storage access through Android settings where applicable.
  • You can uninstall FileLane at any time.
